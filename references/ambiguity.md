## 四、过度繁化与生僻字陷阱（《活侠传》9.2万条实测）

实测发现 OpenCC 在很多常见词上存在**过度生僻化、机械切分或漏转正字**的问题，必须依靠内建修正表（`CORRECTIONS`）进行兜底：

| 现象 / 词组 | 简体原文 | OpenCC 错误输出 | 官方正确正字 | 原因分析与应对 |
|---|---|---|---|---|
| **娘字过度繁化** | 战你娘亲、师娘 | 戰你**孃**親、師**孃** | 戰你**娘**親、師**娘** | 「娘」在繁体本为正字，「孃」为异体。现代台湾绝少用「孃親」「師孃」，内建修正兜底 |
| **动词误判戏剧量词** | 小爷我一出手 | 小爺我**一齣手** | 小爺我**一出手** | OpenCC 看到「一出」误判为戏剧折子量词「一齣」，动作「一出手」被误伤 |
| **方言俚语误伤** | 仙人板板 | 仙人**闆闆** | 仙人**板板** | 四川方言俚语，OpenCC 强行把「板」转成老板之「闆」 |
| **典故生僻化** | 心有戚戚 | 心有**慼慼** | 心有**戚戚** | 教育部辞典正字为「心有戚戚焉」，OpenCC 滥用生僻异体「慼」 |
| **俗体漏转正字** | 彷佛已是既定之数 | 彷**佛**已是既定之數 | 彷**彿**已是既定之數 | 简体中常写「彷佛」，OpenCC 遇到该写法无法转出正字「彿」，内建修正兜底 |
| **亲属称谓漏转** | 师侄、贤侄、侄女 | 師**侄**、賢**侄**、**侄**女 | 師**姪**、賢**姪**、**姪**女 | 台湾教育部规定亲属同门称谓正字为「姪」，OpenCC 漏转保留「侄」 |
| **财务正字偏好** | 算账、买账、混账 | 算**賬**、買**賬**、混**賬** | 算**帳**、買**帳**、混**帳** | 台湾教育部辞典正条统一使用「帳」，OpenCC 偏好后起字「賬」 |
| **盲点误转「干」** | 干着急、干瞪眼 | **幹**著急、**幹**瞪眼 | **乾**著急、**乾**瞪眼 | 表白白、徒然的「干」应转「乾」，OpenCC 误转为「幹」 |

## 五、术语保护的两个坑

1. **OpenCC 已能正确处理常见专名**。实测「千里走进里面」→「千里走進裡面」，没有把千里转成千裡。所以保护表不是用来救常见词的，而是救游戏自造词与多音专名。
2. **占位符不能与原文字符冲突**。使用 Unicode 私用区 `\uE000` 起头的标记，正常文本不会出现。术语数量多时用序号区分。

## 六、标点的边界情况

| 情况 | 处理 |
|---|---|
| `"hello"` 英文直引号 | 先隔离整段，不转换 |
| `“外「内」外”` 已含中文引号 | 不重复转换 |
| `他说：“好。”` | 句号保留在引号内 |
| `……」` | 省略号在引号内，不加句点 |
| JSON、变量名、控制符 | 一律不动 |
| 长度为零的行 | 跳过，不产生空占位 |

## 七、繁体歧义目标字过滤（转后筛查）

一简对多繁的歧义检测存在两个不同阶段的视角：
- **转换前（简体视角）**：使用 `ambiguousSet()`（146 个一简多繁简体来源字），用于在基线转换前普查文本的歧义规模。
- **转换后（繁体视角）**：基线转换跑完后，文本已全部变为繁体，原文的简体字（如 `发`、`干`、`面`、`里`）已被替换为某一个繁体字形（如 `發`、`乾`、`麵`、`裡`）。此时若再用简体字集过滤繁体文本，不仅命中率为零，还会遗漏由于词库未覆盖而转错的繁体字（例如「理發」误转未成「理髮」）。

因此，转后复查应使用**繁体歧义目标字集**（`ambiguousTargetSet()`，共 298 字）。

### 2. 用法示例

在基线转换完成后，使用 `hasAmbiguousTarget` 过滤出含有上述高危字的条目，仅将这些句子送交模型进行上下文判断：

```javascript
const { hasAmbiguousTarget, ambiguousTargetCensus } =
  await import(new URL("scripts/s2t.mjs", base_url).href);

// 1. 过滤含有繁体目标歧义字的待复查条目
const candidateItems = items.filter(it => hasAmbiguousTarget(it.message));

// 2. 统计当前批次繁体歧义字出现频次
const stats = ambiguousTargetCensus(items.map(it => it.message).join("\n"));
```
