# 用词白名单与误伤记录

只用于在地化档（`s2twp`）。保真档不读本文件。

## 一、zone 的判定

| zone | 含义 | 举例 |
|---|---|---|
| `any` | 任何区域都替换，含义不会歧义 | 软件→軟體、网络→網路 |
| `ui` | 只在游戏 UI、系统文本替换 | 文件→檔案、程序→程式、信号→訊號 |
| `narrative` | 只在叙述里替换（较少用） | 视情况 |

拿不准的词一律标 `ui`，宁可少转。

## 四、已知误伤案例（不要无脑转）

实测 s2twp 的过度替换，每条都是真实句子：

| 原文 | s2twp 输出 | 问题 |
|---|---|---|
| 这份文件很重要，务必亲手交给将军 | 這份**檔案**很重要 | 公文不是计算机文件 |
| 这件事的程序还没走完 | 這件事的**程式**还没走完 | 行政程序 |
| 信息学院的教授来了 | **資訊**學院的教授來了 | 学院专名 |
| 心知讨不了好，便招呼发射信号 | 招呼發射**訊號** | 武侠/古代发射穿云箭、鸣镝是「信號」，不是电子讯号 |
| 这个视频记录了当时的场景 | 這個**影片**記錄了 | 可接受但改变语感 |
| 他的质量很好 | 他的質量很好 | 未替换，正确 |

结论：含 IT 词的句子必须先看语境。叙事区一律退回保真档。

## 七、词表维护

- 新词先标 `ui`，跑过 diff 报告再考虑提到 `any`
- 发现一次误伤就记一条，写进本文件第四节
- 词表按最长匹配优先，短词不会吃掉长词
- 同一词在两区含义不同时，拆成两条分 zone 配置
